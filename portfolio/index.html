02 — About

I like the part
where it gets hard.

I'm a final-year CS student who learns by shipping. Give me a blank repo and a real problem — auth, payments, file pipelines, AI that has to behave — and I'll come back with something that works end to end.

Most of what I know came from breaking things in side projects and then fixing them properly: reading the stack trace, tightening the validation, writing the test that would have caught it. I'm looking for internships and collaborations where I can keep doing that with a team.

  • 01

    Own the whole stack

    If it ships, I want to understand it — from the React tree to the Express route to the Mongo index.

  • 02

    Security is a feature

    Validated uploads, hashed passwords, scoped sessions, client-safe errors. Boring on purpose.

  • 03

    Make it feel alive

    Real loading states, useful motion, and micro-interactions that guide instead of showing off.
